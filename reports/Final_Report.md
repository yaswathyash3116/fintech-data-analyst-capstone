Mutual Fund Analytics Capstone Project

Author: Yaswanth kumar
Project Type: Fintech Data Analyst Capstone
Date: June 2026

Summary:-
        This project analyzes mutual fund investment data to understand investor behavior, SIP trends, fund performance, and portfolio insights. The project includes data cleaning, exploratory data analysis, advanced analytics, and dashboard development using Power BI. The goal is to provide meaningful insights for investors and financial decision-makers.

Project Objectives:-
1. Analyze investor behavior.
2. Study SIP inflow trends.
3. Evaluate fund performance.
4. Identify key investment patterns.
5. Build interactive dashboards.
6. Generate actionable business insights.

Data Sources:-
            The project uses multiple mutual fund datasets containing investor information, SIP transactions, fund performance metrics, and portfolio details.

Datasets were cleaned, validated, and transformed before analysis.

## ETL Design

### Extract

Data was collected from multiple mutual fund datasets containing investor details, SIP transactions, fund performance metrics, and portfolio information.

### Transform

The datasets were cleaned by:

- Removing duplicates
- Handling missing values
- Standardizing column names
- Converting data types
- Validating records

### Load

The cleaned datasets were loaded into analysis notebooks and Power BI dashboards for visualization and reporting.

## Exploratory Data Analysis Findings

The exploratory data analysis identified several important patterns in the mutual fund data.

### Key Findings

1. SIP inflows showed consistent growth over time.

2. Certain mutual funds consistently outperformed others based on returns.

3. Investor participation increased significantly in specific periods.

4. Portfolio diversification positively impacted overall performance.

5. High-performing funds demonstrated better risk-adjusted returns.

## Performance Analysis

### Fund Performance

The performance analysis compared mutual funds using return-based and risk-adjusted metrics.

### Observations

1. Top-performing funds generated consistently higher returns.
2. Risk-adjusted measures helped identify stable funds.
3. Diversified portfolios showed lower volatility.
4. Long-term investments generally outperformed short-term strategies.

## Dashboard Insights

The Power BI dashboard provides interactive visualizations for investor behavior, SIP trends, and fund performance.

### Dashboard Features

- Investor analysis
- SIP trend analysis
- Fund performance comparison
- Portfolio insights
- Interactive filtering and drill-down capabilities

## Limitations

1. Analysis is limited to the available datasets.
2. Historical data coverage may not represent all market conditions.
3. External economic factors were not included in the analysis.
4. Future performance cannot be guaranteed based on historical trends.

## Recommendations

1. Encourage long-term SIP investments for wealth creation.
2. Maintain diversified portfolios to reduce risk.
3. Monitor fund performance periodically.
4. Use risk-adjusted metrics while selecting funds.
5. Incorporate additional market indicators in future analysis.

## Conclusion

This Mutual Fund Analytics Capstone successfully analyzed investor behavior, SIP trends, and fund performance using data analytics techniques. The project demonstrated the complete analytics lifecycle, including data collection, cleaning, exploratory analysis, advanced analytics, and dashboard development. The insights generated can support informed investment decisions and portfolio management.
