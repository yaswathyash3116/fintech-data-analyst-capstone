# Fintech Data Analyst Capstone

## Project Overview

This project analyzes Indian stock market and mutual fund data using Python, Pandas, PostgreSQL, SQL, Flask, and Data Visualization.

## Objectives

- Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Business Questions
- Statistical Insights
- Flask REST API
- Financial Analytics

## Technologies Used

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Flask
- Matplotlib
- Seaborn
- Git & GitHub

- SIP investments showed steady growth.
- Top-performing funds generated consistent returns.
- Diversified portfolios reduced investment risk.
- Long-term investments outperformed short-term strategies.
